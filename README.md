# Agent stack blueprint

Six articles on running AI agents on an open platform, written from public code and public legal texts:

1. [AI agents on OpenShift: the open blueprint, layer by layer](part-1/)
2. [The same agentic stack with no platform vendor](part-2/)
3. [What the regulations actually ask of an agent stack](part-3/)
4. [Action governance with Microsoft's Agent Governance Toolkit](part-4/)
5. [Observability: what the stack records, and what it cannot tell you](part-5/)
6. [Rolling out a model blue/green](part-6/)

Everything here is a reading of code and documents at the dates stated in each article, not something run in production. If something does not match what you see on your cluster, open an issue here or, better, with the project concerned.
